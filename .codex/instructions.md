- Scan the entire project structure
- Identify architecture pattern
- Identify technology stack
- Identify coding standards

For large tasks:
- Create a plan first
- Wait for approval

For bug fixes:
- Find root cause first

For refactoring:

For new features:
- Follow existing architecture

- Maintainability

- Security
- Performance
- Readability
